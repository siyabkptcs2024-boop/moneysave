MoneySave iOS Mobile App
=========================
This is an iPhone-friendly PWA based on your existing Expense Tracker.

Features:
- Income / Expense
- Date, category and note
- Balance, weekly expense and monthly expense
- Delete individual transactions
- Clear all data
- Dark/light mode
- IndexedDB local database (better than localStorage for this app)
- Works without a laptop and without Node/MongoDB

IMPORTANT:
This is an offline/local app. Data stays on the iPhone/browser and does NOT sync to another phone.

iPhone setup:
1. Open index.html through a web host/browser that can serve the files.
2. In Safari tap Share -> Add to Home Screen.
3. Open MoneySave from the Home Screen.
